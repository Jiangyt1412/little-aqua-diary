# 小小水族日记 · 精简版 1.2

手机优先的个人饲养记录工具。三个入口：首页、记录、居民。五个初始缸及物种信息保留，不添加虚构的维护记录。

[在线使用](https://little-aqua-diary-jyt.jiangy-t-10.chatgpt.site)。原有私有访问范围保持不变，托管入口可能要求身份验证；应用没有独立账号、业务后端或云端同步。

## 日常使用

- 首页卡片直接点击喂食、吸便、加水，即记录当前时间。短时间双击不会重复保存，提示中可撤销；进入记录编辑可补记过去的时间。
- 换水填写升数或比例，也可以只记时间。观察可写文字、添加照片，或只上传照片；每条最多三张。
- 点击缸名或像素场景，进入这个缸的喂食月历、当月维护记录和居民名单。日期可以点击，月份可以切换。月历分别统计喂食次数和有记录的天数；空白日期只代表没有记录。
- 首页物种和数量可以直接点击修改。新增物种、移动到另一个缸、精确/约数/区间/未知/文字数量均支持。
- 「新增生物」选择已有物种或填写新物种，填入新增的正整数只数，保存后同步更新该缸居民。新物种自动建立居民组，非黑壳虾也建立可命名的个体档案。
- 居民页中，非黑壳虾的个体可以分别取名字、上传头像和填写体长。同种的两条鱼有两个独立档案。黑壳虾仍按组管理数量。
- 记录页支持关键词搜索；缸、类型、日期筛选收在筛选按钮中。点击笔形按钮编辑，删除在编辑弹窗内。
- 右上角齿轮只保留备份、恢复、导出表格和清理记录。背景、主题切换、独立数据页已移除。

不常用的死亡、新增生物、用药、加盐、设备维护、检测和自定义事件仍可通过「记一笔」或缸内「其他记录」保存。水质参数没有独立趋势页；既有检测记录仍可搜索和编辑。

## 名单与旧数据

浏览器原有的版本 1 数据与 JSON 备份继续兼容，沿用同一个存储键。旧喂食中的食物和用量、旧加水量、检测数值等保留；编辑时间时不会清掉原有详情。旧吸便/换水配对仍同步容器、时间、换水量，删除时会提示一起移除。新吸便只记录时间，不自动生成换水。

新版新增生物记录联动居民数量：精确数量直接加数，约数继续是约数，区间的两端同时加数。原数量未知或只有文字描述时，显示「待统计 · 新增 X 只」，不推断总数。两桶的原始约 80 只不作为现存数量；待确认的物种继续保留标记。死亡事件仍由使用者盘点并更新名单。

编辑已联动的新增记录仅调整差值；改缸或物种组会迁移本次新增个体，已有名字和头像保留。减少数量会提示将移除的已命名/有头像个体。删除联动记录默认撤销本次新增，也可以选择「仅删除记录，保留居民」。数量不足或名单已手动改变、无法安全撤销时，不会误减其他居民；可核对名单或选择只删记录。

清空维护记录保留当前居民及累计新增信息。既有未联动的历史新增记录不追溯加数，编辑或删除也只影响历史；旧记录已可能由手动盘点计入。JSON 备份保留联动关系，恢复后仍能正确编辑和撤销。

精确数量的非黑壳虾会生成对应数量的个体档案；每组最多显示 200 个，适用于家庭饲养规模。非精确数量不据此假定实际个体，只保留已建立的档案或一个命名入口。减少数量会从名单末尾移除个体；若这些个体已有名字或头像，界面会先确认。

当前像素场景为原创 SVG 插画，固定使用。尚未收到实鱼照片，不能宣称对应实际个体；收到照片后可替换为依照照片制作的像素素材。头像上传显示用户照片，不自动生成像素画。

## 照片与备份

维护记录和名单保存在当前浏览器的 localStorage，照片以 Blob 保存在同一网址的 IndexedDB。照片不上传服务器。浏览器存储随设备、浏览器、网址而隔离，不自动跨手机和电脑同步。

上传支持 JPEG、PNG、WebP，每张输入小于 20 MB。观察图片最长边压缩至最多 1440 px；头像中心裁成 480 × 480 px，保存为 JPEG。它们用于日常记录，原始照片请另行保留。

「备份（含照片）」导出完整 JSON，包含当前名单、记录、头像与观察照片。恢复时先检查数据和照片，确认后才替换；写入失败会清理本次新图片、保留旧数据。照片缺失的备份会被拒绝。旧版无照片 JSON 仍可恢复。最大备份文件为 256 MB。

「导出记录表格」生成 CSV，含时间、类型、缸、详情、备注和照片数量，不包含图片二进制，也不能用于恢复。CSV 使用 UTF-8 BOM、引号转义和公式防护。

照片从记录移除后不进入新备份；旧图片缓存可能仍留在浏览器数据库中。记录或头像没有持久云端副本；清理网站数据、隐私浏览结束或设备损坏可能使其丢失。换手机、浏览器或网址前，请导出含照片 JSON 并保留在浏览器之外。在线版与本地版也用备份手动迁移。

参考：[MDN：IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API)、[MDN：Canvas 图片输出](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/toBlob)。

## 本地运行

无前端依赖或构建步骤，需要 Python 3。

- macOS：双击项目内 `启动水族日记.command`。
- Windows：安装 Python 3 后双击 `启动水族日记.bat`，打开 `http://127.0.0.1:4173/`。
- 或在项目目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist # 仅提供静态网页；保持启动窗口打开
```

停止服务按 Ctrl+C。直接双击 HTML 可能受浏览器模块限制；电脑的 127.0.0.1 仅适用于这台电脑。手机可使用在线地址。本版没有 PWA 离线安装。

## 源码与检查

`dist/` 是完整静态应用。`js/data.js` 管理初始数据和事务，`inventory.js` 管理新增联动与撤销，`logic.js` 处理日期、月历和搜索，`media.js` 处理照片及恢复，`forms.js`、`ui.js`、`app.js` 分别负责表单、页面和交互；`art.js` 是原创像素插画和图标。

Node.js 20+ 可运行无依赖的数据测试：

```sh
npm test # 校验新增联动和回滚、旧备份、照片引用、个体档案、闰月、搜索和 CSV
```

浏览器验证范围见 `验收记录.md`。模拟手机视口检查不等同于 iPhone/Android 实机测试；软键盘、相册格式和下载行为仍取决于设备浏览器。
