# v1.6.8 产品短片制作

介绍页、封面与短片统一纸白背景，直接展示真实 App，采用细轮廓与短文案。移除硬件外壳、旋转屏幕、圆形几何背景、悬浮居民和章节背景切换。当前页只提供产品短片；旧操作录像保留为历史文件。

`studio.html` 保存可重复渲染的镜头布局。单条高分辨率真实 UI 操作录像贯穿全片，相机使用连续插值移动，版式不修改 App 内容。图标与像素形象来自项目现有资源。

操作帧在隔离演示浏览器中录制；截图原始尺寸 1170 × 2532，操作帧 30fps，最终镜头按 60fps 输出 1920 × 1080、24秒。系统字体由制作设备提供。演示记录与名字为虚构样例，观察图及头像为原生像素插画，不读取用户资料。

`score.py` 保留原创程序合成配乐，无外部歌曲、采样或第三方授权音乐。本版剪裁至24秒，并平滑淡入、淡出；生成中间音频不提交。

公开素材位于 `dist/media/`，文件名包含当前版本；关键帧与实际浏览器检查记录保存在制作工作区。浏览器模拟不等于实体 iPhone 验证。

参考 [Playwright 录制文档](https://playwright.dev/docs/videos) 核对原录制尺寸；本版直接采集高分辨率页面帧，避免把低分辨率视频放大。原生界面过渡通过可控录制时钟和 Web Animations 采样同步，最终素材仍由真实 App 渲染。
