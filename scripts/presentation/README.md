# v1.6.5 产品展示制作

`studio.html` 保存封面、四个功能镜头与片尾的排版和确定性动效。镜头内容使用当前版本的真实界面，外框是通用手机展示容器，不代表 iPhone 实机拍摄。字体来自制作设备的系统字体。

`score.py` 使用 Python 标准库合成32秒原创配乐，无外部歌曲、采样或授权素材。运行后生成的 `score.wav` 仅作制作中间文件，不提交。公开成片已包含 AAC 配乐。

公开结果位于 `dist/media/`：`cover-v1.6.5.jpg`、`story-*-v1.6.5.jpg`、`demo-v1.6.5.mp4`、`product-preview-v1.6.5.gif` 及字幕。实际操作录像另存为 `walkthrough-v1.6.5.mp4`，与广告短片分别提供。

截图和录制使用隔离实例的演示备份。名字与记录为示例，照片附件是项目原生像素插画。未读取或公开用户的浏览器资料。广告中的每个 App 画面均来自实际页面或录屏；逐帧合成只修改展示排版和镜头位置。

版式参考 [Apple 产品页面](https://www.apple.com/iphone/) 的产品层次与短文案，以及 [Things 官方介绍](https://culturedcode.com/things/) 的软件展示方式。外部产品截图、商标、广告视频和音乐未加入本项目。

原始演示录像与逐帧渲染的中间文件保存在本次制作工作区，不是线上 App 所需文件。未来功能发生变化时需重新录制，不应仅替换版本号。
