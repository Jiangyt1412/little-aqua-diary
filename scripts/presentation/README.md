# v1.6.11 产品短片制作

介绍页、封面与短片共用项目原生 SVG 水域背景，端正展示真实 App，采用细轮廓与短文案。以柔和水色、水纹、像素水草及岩石丰富空白，不增加介绍文案或外部品牌背书。首屏左右分区与双屏错位参考用户提供的 DayFlow 版式截图，未复制其产品界面。

`studio.html` 保存可重复渲染的镜头布局。重新采集 v1.6.11 的单条20秒高分辨率真实 UI 操作录像，相机使用连续插值移动；本版把7.3–12.3秒的居民段替换为维护月历，显示真实 App 根据示例记录生成的按日图标与次数；文案改为“这一月，一眼回看。”，其余镜头顺序与水域背景保留。当前页只保留产品短片入口，历史录像保留原文件。

真实操作源尺寸1170 × 2532、30fps；最终镜头60fps、1920 × 1080、24秒。素材使用隔离演示资料，名字与记录为示例，头像与观察附件为项目原生像素插画，没有读取用户资料。系统字体由制作设备提供。

`score.py` 保留原创程序合成配乐，无外部歌曲或采样；剪裁至24秒并淡入淡出，中间音频不提交。六段中文字幕保留。

公开素材位于 `dist/media/`，文件名包含当前版本；制作工作区保存关键帧和实际浏览器检查记录。首页、居民、记录、月历及暂停界面采集自本次演示资料；未改变的头像取景与时间轴特写保留原素材。月历段的示例记录分布在制作日以前，不能视为养护建议。浏览器模拟不等于实体 iPhone 验证。

最终发布MP4使用H.264、veryslow预设、CRF 21压缩并启用faststart，保留24秒、1080p、60fps及原创配乐的96kbps双声道AAC编码；动图从最终发布文件中的月历段生成。压缩后重新执行完整解码与浏览器播放检查。
