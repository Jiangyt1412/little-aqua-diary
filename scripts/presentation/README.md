# v1.6.9 产品短片制作

介绍页、封面与短片共用项目原生 SVG 水域背景，端正展示真实 App，采用细轮廓与短文案。以柔和水色、水纹、像素水草及岩石丰富空白，不增加介绍文案或外部品牌背书。首屏左右分区与双屏错位参考用户提供的 DayFlow 版式截图，未复制其产品界面。

`studio.html` 保存可重复渲染的镜头布局。沿用 v1.6.8 已验证的单条20秒高分辨率真实 UI 操作录像，相机使用连续插值移动；本版重新渲染背景，App 的功能界面未变。当前页只保留产品短片入口，历史录像保留原文件。

真实操作源尺寸1170 × 2532、30fps；最终镜头60fps、1920 × 1080、24秒。素材使用隔离演示资料，名字与记录为示例，头像与观察附件为项目原生像素插画，没有读取用户资料。系统字体由制作设备提供。

`score.py` 保留原创程序合成配乐，无外部歌曲或采样；剪裁至24秒并淡入淡出，中间音频不提交。六段中文字幕保留。

公开素材位于 `dist/media/`，文件名包含当前版本；制作工作区保存关键帧和实际浏览器检查记录。截图沿用未改变的实际 App 界面，不能据新素材名称推断本版更改了 App 功能。浏览器模拟不等于实体 iPhone 验证。

最终发布MP4使用H.264、CRF 21压缩并启用faststart，保留24秒、1080p、60fps及原AAC配乐；动图从最终发布文件生成。压缩后重新执行完整解码与浏览器播放检查。
