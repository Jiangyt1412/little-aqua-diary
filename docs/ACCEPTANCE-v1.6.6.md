# v1.6.6 验收记录 · 2026-10-20

本次交付包括项目展示重做，以及正式站点复测发现的首次播放修复。v1.6.5 已发布并保留，见 [上一版验收](ACCEPTANCE-v1.6.5.md)。

- 版本信息与图标异步加载，不阻塞播放器的首次点击。自定义播放按钮仅在事件绑定后出现，原生视频控制一直可用。
- 保留32秒1920×1080、30fps产品短片和原创配乐，以及52.40秒完整实际录屏；片尾、字幕、封面和原生像素海报同步当前版本。
- 全部素材来自隔离演示实例，日记与照片数据格式保持不变。原生像素头像与演示记录不包含个人浏览器资料。
- 具体浏览器与发布验证结果保存在本次制作工作区。未做实体 iPhone 或 Safari 真机测试，没有安装第三方依赖。

本地最终验证：81项 Node 测试、22个前端模块语法与发布一致性检查通过；320 / 390 / 768 / 1440 px 无整页横向溢出且图片均可解码；两类影片实际播放、切换、暂停、源失败后重试和减少动态效果通过。元数据请求人为保持未完成时，一次点击即开始播放；元数据与图标同时失败时仍可播放；关闭脚本时原生视频控制保留。

以已发布 v1.6.5 为起点的升级测试通过：资源缺失时保留旧版、完整 JSON、头像及取景副本，恢复完整资源后自动重开；七条记录、暂停原因、旧标题、图标与头像再次裁剪保留。GitHub 与正式部署状态另行核对后才确认上线。
