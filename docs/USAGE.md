# 使用与备份（v1.4.0）

[打开水族日记](https://jiangyt1412.github.io/little-aqua-diary/) · [图文与视频简介](https://jiangyt1412.github.io/little-aqua-diary/intro.html)。主界面只有首页、记录、居民三个入口。

## 从空白开始

新日记没有预设缸、居民或维护记录。点击「创建第一个缸」，填写名字，选择水草庭院、溪流石岸、湖畔微光或苔藓浅滩；之后可编辑。

在缸内添加居民，选择像素形象、物种和数量。十二种形象包括鲫鱼、黑壳虾和黄金玻璃猫孔雀鱼；孔雀鱼按用户描述绘制为黄色尾巴、粉色半透明身体、黑色眼睛。形象用于标签、默认头像和缸景，不据此鉴定物种。选择该孔雀鱼时建议数量 4，可修改，不会自动创建。

非黑壳虾的个体可以分别命名、选形象、上传头像和填写体长；黑壳虾按组管理。上传照片后显示照片头像，不会自动转换成像素画。减少有名字或照片的个体前会确认。每组最多建立 200 个个体档案；约数、区间或未知数量不被当作实际个体总数。

旧个人数据和含照片 JSON 保留。只有与原版完整默认配置完全相同、从未修改且没有记录或提醒的资料，首次升级才自动转为空白。修改过的名字、数量、设置或记录均不自动清除。需要重新开始时，在「管理与备份」选择「重新开始 · 空白日记」；先备份再确认。

新版不再自动合并旧名单。此前已经保存的合并结果保持原样；未合并的旧组也按原资料保留，可自行修改。

## 日常记录

- 喂食、吸便、加水一点即记录当前时间，短时间双击不重复保存；提示中可撤销，记录编辑可补记时间。
- 换水可填写升数或比例；观察可写文字或添加照片，每条最多三张。
- 点击缸名或像素场景，查看该缸喂食月历、维护记录和居民。月份和日期可切换；空白日期只表示没有记录。
- 首页物种和数量可直接修改。「新增生物」记录会同步更新缸内名单；编辑只调整差值，删除可撤销本次新增或仅删除记录。
- 记录页按关键词搜索；缸、类型、日期收在筛选中。低频事件通过「记一笔」添加，旧检测记录仍可搜索和编辑。

数量未知或只有文字时，新增只累计「待统计 · 新增 X 只」，不推断总数。死亡事件由使用者盘点并更新名单。旧版未联动的历史新增不追溯加数。改缸或修改已联动新增时保留个体资料；若名单后来发生变化，无法安全撤销则提示核对，不误减其他居民。清空记录保留当前名单。

## 提醒与日历

右上角铃铛或缸详情可创建喂食、吸便、换水、加水提醒，设置开始日期、当地时间和每隔几天。到期或未完成任务在 App 内显示；「完成并记录」保存一次相应维护。普通同缸同类型维护也可满足已到期任务。未完成的任务保留到处理，不自动补造历史记录。

暂停时可写原因，例如「生病，需要控制饮食」。恢复后从当天重新计算计划，原暂停原因保留在备份中。

「导出日历文件」生成 `.ics`，仅包含启用中的任务，带重复规则和事件时间提醒。iPhone 可把文件作为附件，通过 Apple「邮件」打开并导入日历。[Apple 官方说明](https://support.apple.com/zh-cn/guide/iphone/ipha0d932e96/ios)

导出文件是当时的快照。之后在 App 中暂停、编辑或删除任务，不会自动更新已导入的日历；请同步调整日历中的旧事件，避免重复导入。实际通知取决于日历权限和设备设置。原生日历导入与锁屏通知没有在实体 iPhone 上实测。

## iPhone 主屏幕与离线使用

Safari 打开在线地址，选择「共享 → 添加到主屏幕」，开启「作为网页 App 打开」后添加。[Apple 官方说明](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/ios)

首次联网成功缓存应用后，可在没有网络时查看缸、居民和已存照片，新增维护记录。项目简介、视频和外部说明需要联网。发布新版时联网重新打开；出现更新提示后重开日记查看版本。

App 的记录、照片和缓存属于当前设备与网址。不同浏览器、Safari 与主屏幕 App 的数据行为可能因系统版本而不同；跨入口前先备份并核对数据。离线缓存不能代替备份。

## 照片与备份

文字与名单保存在 localStorage；照片二进制保存在 IndexedDB，新图片使用字节存储，旧版 Blob 图片仍可读取。照片不上传服务器，不自动跨设备同步。

支持 JPEG、PNG、WebP；HEIC/HEIF 在浏览器支持解码时可用，不支持时会提示换格式。每张输入小于 20 MB；观察图最长边最多 1440 px，头像中心裁成 480 × 480 px，均压缩为 JPEG。原始照片另行保留。

「备份（含照片）」导出完整 JSON，包括缸、居民、记录、提醒、头像和观察图片。恢复前先校验；缺失引用照片则拒绝覆盖，写入失败保留旧数据。无照片的旧 JSON 继续兼容，最大备份 256 MB。「导出记录表格」是带时间、类型、缸、详情、备注和照片数量的 CSV，不能用于恢复。

照片从记录移除后不进入新备份，未引用的旧缓存可能留在浏览器。换手机、换浏览器或换网址前，请导出含照片 JSON，并保存在浏览器之外。清除网站数据、隐私浏览结束或设备损坏可能丢失本地资料。

原入口：[小小水族日记](https://little-aqua-diary-jyt.jiangy-t-10.chatgpt.site/)。从原入口导出备份，在新网址恢复；如果新网址已经有资料，先备份再替换。

## 本地运行与检查

静态网页没有前端依赖或构建步骤。需要 Python 3；macOS 可双击 `启动水族日记.command`，Windows 可安装 Python 3 后双击 `启动水族日记.bat`。

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist # 在项目目录启动，打开 http://127.0.0.1:4173/
```

停止服务按 Ctrl+C。直接打开 HTML 可能受模块限制；电脑的 127.0.0.1 仅适用于这台电脑。手机使用 HTTPS 在线地址。

Node.js 22+ 可执行：

```sh
npm test # 验证数据、联动、旧备份、空白初始化、提醒和日历规则
npm run check:release # 校验版本、更新内容、演示媒体及 PWA 资源
```

`dist/js/data.js` 管理数据事务，`inventory.js` 管理数量联动，`media.js` 管理照片和恢复，`tasks.js` 管理提醒与日历，`pets.js` 与 `habitats.js` 管理原生像素素材，`starter-reset.js` 识别未修改的旧默认配置，`pwa.js` 和 `sw.js` 管理安装与缓存。

实际验证范围见 [验收记录](../验收记录.md)。桌面 WebKit 手机视口测试不等同于实体 iPhone；软键盘、相册选取、系统下载和日历导入仍需在用户设备核对。
