# 使用与备份（v1.6.2）

[打开水族日记](https://jiangyt1412.github.io/little-aqua-diary/) · [图文与视频简介](https://jiangyt1412.github.io/little-aqua-diary/intro.html)。主界面只有首页、记录、居民三个入口。

## 日记名称

点击左上角标题或小铅笔，编辑并保存，最多 20 个可见字。长名称在顶栏均衡换行；首页内容区仅显示年月日与星期。已有 21–24 字名称保留，不自动截断，编辑保存时检查新上限。标题随完整备份恢复。

## 从空白开始

新日记没有预设缸、居民或维护记录。点击「创建第一个缸」，填写名字，选择水草庭院、溪流石岸、湖畔微光或苔藓浅滩；之后可编辑。从记录或添加居民入口开始时，建好首缸后会继续原操作。

在缸内添加居民，选择像素形象、物种和数量。形象按「乌龟、鱼、虾」分区，同款鱼的不同颜色放在一起；卡片只显示图案，点击即可选择。粉色与银黑形象相邻，之后是虾虎鱼；同款五色单独成组并换行。所有卡片等宽等高，图标统一为 62 × 62 px，不再缩小五色形象。居民页右上角只有「添加居民」，进入表单即可选择形象。物种名称可自行修改。十二种形象包括鲫鱼、黑壳虾和黄金玻璃猫孔雀鱼；本版孔雀鱼按新照片绘制为金黄身体与扇尾、红色鳃部、黑眼睛和圆腹。形象用于标签、默认头像和缸景，不据此鉴定物种。选择该孔雀鱼时建议数量 4，可修改，不会自动创建。

居民卡片共用网格，不因四位个体切换到更大的两列卡片；头像尺寸与其他物种一致。

非黑壳虾的个体可以分别命名、选形象、上传头像和填写体长；黑壳虾按组管理。上传照片后先预览裁剪，拖动取景，双指或滑杆缩放，也可旋转、重置；点「使用头像」回到表单，再点「保存」。已有照片可点「裁剪头像」重新调整。取消任一步都不会覆盖已保存头像。照片不会自动转换成像素画。减少有名字或照片的个体前会确认。每组最多建立 200 个个体档案；约数、区间或未知数量不被当作实际个体总数。

旧个人数据和含照片 JSON 保留。只有与原版完整默认配置完全相同、从未修改且没有记录或提醒的资料，首次升级才自动转为空白。修改过的名字、数量、设置或记录均不自动清除。需要重新开始时，在「管理与备份」选择「重新开始 · 空白日记」；先备份再确认。

新版不再自动合并旧名单。此前已经保存的合并结果保持原样；未合并的旧组也按原资料保留，可自行修改。

## 同物种与排序

同缸内相同物种名称合并展示一行，数量汇总；内置彩色鱼的不同颜色按同款展示。原名单不合并、不改名，不同缸独立。精确数量相加；约数仍标「约」，区间仍显示区间，存在未知或文字数量时显示「待统计」，不会推算精确总数。

不同颜色的像素图标并排，个体卡片放在同一组。点击物种或总数可分别编辑原资料；点击颜色图标可进入对应资料。名字与照片仍归属原个体。

长按约半秒后拖动物种行、颜色图标或个体卡片排序。普通滑动仍滚动页面；取消拖动不保存。颜色顺序和个体顺序会对应更新，首页、居民页与缸详情共用排序。键盘聚焦后，可按 Alt 加方向键调整。排序随含照片备份恢复。

## 清理与重置

- **仅清空维护记录**：从日记移除维护历史和记录中的观察照片；保留缸、居民数量、个体名字与头像、日记名称、设置和提醒。由于完成依据的记录被移除，提醒完成状态会重新计算，暂停状态与原因保留。
- **重新开始 · 空白日记**：清空缸、居民、维护记录、头像和观察照片的引用、提醒与排序，日记名称及设置也恢复默认，返回初次打开的空白日记。

两项操作均需确认，确认前可导出含照片备份。取消不更改资料；操作后不能直接撤销，可通过之前的完整备份恢复。这些是日记内容的移除；未引用的旧图片可能仍留在浏览器存储，不能视为设备级文件擦除。

## 按缸时间轴与切页

记录页按天查看，各缸在纵向分别占一行，共用按当天筛选结果范围自动生成的时间标尺；集中在两小时内的记录不再铺开整天。图标位置按本地时刻排列，靠近的事件错层，点击卡片可编辑记录；照片入口可查看观察图片。左侧缸名固定，所有行随同一个横向滚动区域移动。通过日期、前后一天和今天切换；关键词、缸、类型及日期范围筛选保留。没有手动指定某一天时，搜索会显示最新匹配记录所在日。每次先显示当日最多 100 条，可加载更多，不删除未显示的记录。

首页、记录、居民按顺序左右滑动切换，拖动时提前显示相邻页面；短拖回弹，不循环越界。主页面切换从页首进入，再点当前底栏入口可回到顶部。密集记录给时间列适量横向空间，必要时可在图表内横滑，左侧缸名仍固定；表外空白区域横滑切页。长按排序、输入框、弹窗和横向标签不触发切页；桌面可使用触控板横滑或导航按钮。常规 App 内跳转替换当前历史项，不累积很多返回层级。

触摸后的焦点框隐藏；用 Tab 或方向键操作时保留绿色焦点提示，输入文字仍可选择。尊重系统减少动态效果设置。

浏览器边缘返回由系统和浏览器共同处理。本版使用横向滚动边界限制和触摸事件处理减少误返回，不能据桌面模拟承诺每个 iPhone / Safari 版本均完全禁止。相关实现背景可参考 WebKit 的历史问题记录：[历史导航与 overscroll-behavior](https://bugs.webkit.org/show_bug.cgi?id=240183)。不采用强制把用户困在页面的历史栈拦截。

## 日常记录

- 喂食、吸便、加水一点即记录当前时间，短时间双击不重复保存；提示中可撤销，记录编辑可补记时间。
- 换水可填写升数或比例；观察可写文字或添加照片，每条最多三张。
- 点击缸名或像素场景时，详情连续滑入；查看该缸维护月历、记录和居民。喂食、吸便、加水、换水共用一个月历，每天按图标 × 次数显示，上方分别汇总本月次数。点击日期查看当天全部记录，包括观察等其他事件；空白日期只表示这四项没有记录。
- 首页物种和数量可直接修改。「新增生物」记录会同步更新缸内名单；编辑只调整差值，删除可撤销本次新增或仅删除记录。
- 记录页按关键词搜索；缸、类型、日期收在筛选中。低频事件通过「记一笔」添加，旧检测记录仍可搜索和编辑。

数量未知或只有文字时，新增只累计「待统计 · 新增 X 只」，不推断总数。死亡事件由使用者盘点并更新名单。旧版未联动的历史新增不追溯加数。改缸或修改已联动新增时保留个体资料；若名单后来发生变化，无法安全撤销则提示核对，不误减其他居民。清空记录保留当前名单。

## 提醒与日历

右上角铃铛或缸详情可创建喂食、吸便、换水、加水提醒，设置开始日期、当地时间和每隔几天。到期或未完成任务在 App 内显示；「完成并记录」保存一次相应维护。普通同缸同类型维护也可满足已到期任务。未完成的任务保留到处理，不自动补造历史记录。

提醒的创建、保存、暂停、恢复和完成后留在原任务列表，子表单左上角可返回。完成换水任务时可填写升数或比例；编辑已完成记录保留任务关联。

提醒间隔为 1–3650 整数天，每天填 1。创建后在提醒卡片点「暂停」，可选 1、3、7 天、指定恢复日期或手动恢复，并填写原因，例如「生病，需要控制饮食」。按设备本地日历计算天数，在恢复日按原时间和间隔继续；不补出暂停期间的提醒。可点「调整暂停」更改恢复日，或「立即恢复」从当天起算。暂停日期与原因随备份保存，关闭 App 后不需要后台运行，再次打开会按当前日期计算状态。

「导出日历文件」生成 `.ics`，包含运行中的任务和有恢复日期的暂停任务，定时暂停从恢复日开始；等待手动恢复的任务不导出。文件带重复规则和事件时间提醒。iPhone 可把文件作为附件，通过 Apple「邮件」打开并导入日历。[Apple 官方说明](https://support.apple.com/zh-cn/guide/iphone/ipha0d932e96/ios)

导出文件是当时的快照。之后在 App 中暂停、编辑或删除任务，不会自动更新已导入的日历；请同步调整日历中的旧事件，避免重复导入。实际通知取决于日历权限和设备设置。原生日历导入与锁屏通知没有在实体 iPhone 上实测。

## iPhone 主屏幕与离线使用

Safari 打开在线地址，选择「共享 → 添加到主屏幕」，开启「作为网页 App 打开」后添加。[Apple 官方说明](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/ios)

首次联网成功缓存应用后，可在没有网络时查看缸、居民和已存照片，新增维护记录。项目简介、视频和外部说明需要联网。

## 检查与安装更新

在右上角「管理与备份」查看当前版本，点击「检查更新」。发现新版后，可展开更新内容，再点「更新到 v…」。App 下载并校验新版缓存，准备好后自动重开。保持联网直到完成；断网、文件缺失或版本不一致时保留当前应用，重新联网后可重试。升级不清理日记、居民、任务或照片，重要资料仍建议定期导出备份。

从 v1.4.0 首次升级时，旧版还没有「检查更新」按钮。联网打开并等待缓存准备后，刷新或关闭重开一次；「管理与备份」显示 v1.4.1 后，后续更新可使用新按钮。不需要卸载或清除网站数据。

这是主屏幕网页 App 的资源更新，不经过 App Store。已安装主屏幕图标是否自动刷新，取决于 iOS 的实际行为，未在实体 iPhone 验证；图标显示旧图时不要清空数据来处理。

App 的记录、照片和缓存属于当前设备与网址。不同浏览器、Safari 与主屏幕 App 的数据行为可能因系统版本而不同；跨入口前先备份并核对数据。离线缓存不能代替备份。

## 照片与备份

文字与名单保存在 localStorage；照片二进制保存在 IndexedDB，新图片使用字节存储，旧版 Blob 图片仍可读取。照片不上传服务器，不自动跨设备同步。

支持 JPEG、PNG、WebP；HEIC/HEIF 在浏览器支持解码时可用，不支持时会提示换格式。每张输入小于 20 MB；观察图最长边最多 1440 px，头像按选择的取景输出 480 × 480 px，均压缩为 JPEG。新上传头像另存完整取景的压缩副本，随含照片备份恢复；旧版头像基于已保存图片编辑，想找回旧头像已裁掉的部分，需要重新上传原图。原始照片请另行保留。

「备份（含照片）」导出完整 JSON，包括缸、居民、记录、提醒、头像和观察图片。恢复前先校验；缺失引用照片则拒绝覆盖，写入失败保留旧数据。无照片的旧 JSON 继续兼容，最大备份 256 MB。「导出记录表格」是带时间、类型、缸、详情、备注和照片数量的 CSV，不能用于恢复。

照片从记录移除后不进入新备份，未引用的旧缓存可能留在浏览器。换手机、换浏览器或换网址前，请导出含照片 JSON，并保存在浏览器之外。清除网站数据、隐私浏览结束或设备损坏可能丢失本地资料。

原入口：[小小水族日记](https://little-aqua-diary-jyt.jiangy-t-10.chatgpt.site/)。从原入口导出备份，在新网址恢复；如果新网址已经有资料，先备份再替换。

## 本地运行与检查

静态网页没有前端依赖或构建步骤。需要 Python 3；macOS 可双击 `启动水族日记.command`，Windows 可安装 Python 3 后双击 `启动水族日记.bat`。

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist # 在项目目录启动，打开 http://127.0.0.1:4173/
```

停止服务按 Ctrl+C。直接打开 HTML 可能受模块限制；电脑的 127.0.0.1 仅适用于这台电脑。手机使用 HTTPS 在线地址。

Node.js 22+ 可执行：

```sh
npm test # 验证数据、联动、旧备份、空白初始化、提醒和日历规则
npm run check:release # 校验版本、更新内容、演示媒体及 PWA 资源
```

`dist/js/data.js` 管理数据事务，`inventory.js` 管理数量联动，`media.js` 管理照片和恢复，`tasks.js` 管理提醒与日历，`pets.js` 与 `habitats.js` 管理原生像素素材，`starter-reset.js` 识别未修改的旧默认配置，`pwa.js` 和 `sw.js` 管理安装与缓存，`updates.js` 校验 `release.json` 并准备更新。

实际验证范围见 [验收记录](../验收记录.md)。桌面 WebKit 手机视口测试不等同于实体 iPhone；软键盘、相册选取、系统下载和日历导入仍需在用户设备核对。

物种名称按钮使用圆角矩形。触屏点击后不保留鼠标悬停背景；鼠标悬停或按下时有轻微高亮，键盘操作仍显示焦点。长按排序与点击编辑保持原有方式。

首页“今天”展示当天的完整记录，数量与列表一致。编辑文字或照片时保留未修改的原始时间；若主动改为其他日期，会移动到对应日期，仍可在“记录”搜索查看。

记录页会按当前日期和筛选后的记录范围自动调整共用时间轴，窗口改变时重新分轨。缸详情页可从屏幕左侧向右滑返回来源页并恢复滚动位置；直接打开详情时返回首页，顶部也有返回按钮。弹窗支持开合过渡，设备启用减少动态效果时取消动画。原生日历、系统边缘手势仍以实际手机行为为准。
