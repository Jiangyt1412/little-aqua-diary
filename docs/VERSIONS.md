## 三段数字怎样区分

本项目后续使用三段式产品版本约定，参考 [Semantic Versioning 2.0.0](https://semver.org/lang/zh-CN/)。严格 SemVer 是针对明确的公共 API 的兼容性；本项目在功能、数据和备份兼容性的维护中采用以下约定。

| 段位 | 何时增加 | 例子 |
| --- | --- | --- |
| 主版本 X | 接口或数据格式出现不兼容变更，需明确迁移说明 | 1.5.2 → 2.0.0 |
| 次版本 Y | 增加兼容的新功能，或较大的功能改进；末位归零 | 1.5.2 → 1.6.0 |
| 修订号 Z | 兼容的问题修复、文案或视觉微调 | 1.5.2 → 1.5.3 |

数字从左到右逐段比较，不是小数：1.4.10 比 1.4.9 新，1.5.0 比全部 1.4.x 新。版本号不代表必须更新多少次，也不直接证明软件质量。已发布内容有任何修改，都使用新版本，不覆盖原版本。

此前的 1.4.1、1.4.4、1.4.5 含新增功能，编号没有严格区分功能与修复；不把这些历史记录描述为严格遵循 SemVer，也不改写其版本号。

## 怎样确认手机用了哪版

打开「管理与备份」看当前版本，再点「检查更新」看服务器版本及本次变化。有新版时保持联网并使用更新按钮，完成后核对当前版本。只看到 GitHub 源码更新或简介里的新版本，不能证明手机缓存已经更新。更新不要求清空日记或卸载 App。
