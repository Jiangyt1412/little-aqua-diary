# v1.6.4 验收记录 · 2026-10-20

本版关闭首页、记录、居民之间的左右滑动切页，保留导航按钮、详情返回、图表滚动和居民排序。历史全量审计见 [v1.6.1 产品审计](AUDIT-v1.6.1.md)。

- 81 项 Node 测试、23 个前端 JavaScript 语法、版本与发布媒体检查通过；主分区手势和详情方向边界的断言已更新。
- 独立 Chrome 使用 390 / 1440 px 视口，三个分区分别验证鼠标左右拖动和横向滚轮不切页；390 px 下用原生 CDP 触摸验证双向与两侧边缘滑动，URL 保持当前页且没有产生切页覆盖层。
- 底部及桌面导航按钮、键盘 Enter、普通纵向滚动和点击当前入口回顶部正常。切页按钮保留原有动画。
- 三个分区都能点击进入鱼缸，采样到实际连续滑入中间帧；从详情左缘右滑返回对应来源和原滚动位置。短拖、中部起点和反向松手不返回，减少动态效果下按钮返回可用。
- 记录页原生触摸横滚实际改变图表滚动位置，不切换分区；导航操作前后原始日记 JSON、头像和完整取景副本散列一致。
- 头像旋转后取消、实际触摸长按排序、取消排序及过渡中改变窗口大小通过；排序只修改排序设置，居民和记录数组保留。
- 从实际已发布 v1.6.3 源码验证更新：导航模块下载失败时保留旧版和旧图标，重试完整资源后自动重开；原始 JSON、七条记录、暂停原因、旧标题、头像与完整取景副本保留，旧头像仍可重新裁剪。
- 当前 51.60 秒、780×1688 MP4 实际播放通过；录屏展示主区滑动后停留原页、按钮切页及保留的详情返回。6.6 秒鱼缸进出动图来自实际录屏，开头和结尾为首页。
- 简介 320 / 390 / 768 / 1440 px 无整页横向溢出，全部图片解码通过，旧缓存模拟下仍显示当前版本。
- 当前 14 张图片及动图关键帧经视觉检查，仅含明确标注的演示日记、演示缸、居民与原生像素插画。没有使用个人浏览器资料和照片，图标与审核通过的形象保持不变。
- 本环境没有可用 WebKit 和 iPhone 真机，未安装新依赖；不把桌面 Chrome 的模拟触摸称为 Safari 系统手势、安全区或软键盘真机验证。
- 上传后另核对 GitHub 首页、Actions、正式网址版本与文件；只有线上部署成功且核验一致才确认发布完成。
