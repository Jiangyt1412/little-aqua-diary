- 85 项 Node 测试通过，包含 4 项键盘视口边界测试；前端模块语法与发布一致性检查完成后核对发布包。
- 320 / 390 / 430 px 手机视口及 1280 px 桌面：真实点击输入、指定恢复日期、手动恢复、取消不覆盖、从输入焦点直接保存与键盘焦点反馈通过。
- 模拟 VisualViewport 可见高度 420 / 320 / 240 px 与顶部偏移，原因输入区不与操作栏重叠，正文独立滚动；这不是实体 iPhone 键盘验证。
- 隔离演示资料完成完整操作回归：七条记录首条编辑后保持时间和总数、缸详情过渡与返回、等大居民卡片、头像裁剪取消、搜索照片、筛选、维护月历、提醒暂停/恢复、换水量与更新检查。没有脚本错误。
- 以真实已发布 v1.6.6 为起点，模拟新版 sheet-layout.js 下载失败：拒绝安装并保持旧版。恢复文件后安装成功并自动重开；原始日记 JSON、七条记录、暂停原因、头像成品与取景副本 SHA-256 保持一致，旧头像可再次裁剪。
